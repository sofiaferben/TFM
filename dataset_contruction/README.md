
# `dataset_contruction/`

This folder contains all the components related to the **dataset construction** phase of the Master's Thesis project. It includes raw data, cleaned data, and the code used to process it. The goal of this phase is to prepare a clean and structured dataset for downstream modeling and evaluation.

---

##  Folder Structure

| Folder/File     | Description                                                        |
|----------------|--------------------------------------------------------------------|
| `code/`         | Jupyter notebooks and scripts for dataset preprocessing and cleaning. |
| `data/`         | Organized datasets: raw input and cleaned output.                  |

---

##  Workflow Overview

1. **Raw data** is collected and stored under `data/raw/`.
2. **Processing notebooks** in `code/` handle tasks such as:
   - Loading and exploring the dataset
   - Cleaning and transforming the data
3. **Processed data** is saved to `data/clean/` for use in modeling.
